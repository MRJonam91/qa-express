# QA Express

**Web QA pilot: one critical flow, reproducible findings, clear coverage.**

[Italiano](README.it.md) · [Illustrative report](examples/report.md) · [Checklist](templates/checklist.md) · [Service scope](docs/SERVICE.md)

This public service portfolio contains a reviewed report format, a delivery checklist and a static landing page. **The example is fictional, not a customer audit.** It makes no claims about measured revenue impact or certification. No SaaS, crawler or automated audit engine is included.

## Pilot scope

One agreed flow (contact form, registration, cart or test checkout), up to five pages on one site. Desktop Chromium and a 390 px mobile viewport; basic keyboard and accessibility observations. Mobile emulation does not establish real iPhone, Android or Safari compatibility.

Proposed pilot price: **€199**, subject to written scope, availability, applicable tax treatment and marketplace terms. Proposed delivery: two working days after access and scope are confirmed. Includes a report with environment, steps, expected/observed behavior, actual evidence and agreed priorities; one recheck within seven days, capped at 30 minutes. Findings may be zero. Fixes, pentesting, load tests and compliance certification are separate.

## Use the materials

Open `site/index.html` in a browser or serve the folder locally. The Italian landing has no backend, analytics, payment form or data collection. A browser with an email client can use the email link; LinkedIn and the website are alternative contacts. Do not use a public issue as client intake.

Copy the checklist for an **authorized** test and write findings using the example structure. Collect only necessary evidence, redact it and deliver privately. A report with no findings should still state coverage and limitations. No legal or accessibility certification is offered.
