# Terze parti / Third parties

Nessuna dipendenza runtime, font, immagine o libreria incorporata. I collegamenti a GitHub, LinkedIn, Playwright, n8n e altri servizi non implicano affiliazione. / No runtime dependencies, embedded fonts, images or libraries. Links to external products do not imply affiliation.

La pipeline GitHub usa actions/checkout (MIT) e actions/setup-python (MIT), scaricati da GitHub nel runner; non redistribuiti nel pacchetto. / The CI workflow fetches these MIT-licensed actions at runtime; they are not bundled.
