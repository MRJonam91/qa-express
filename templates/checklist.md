# Checklist QA a perimetro fisso / Scoped QA checklist

- [ ] Autorizzazione scritta, referente e scope confermati / Written authorization, contact and scope confirmed.
- [ ] Un flusso, massimo 5 pagine, azioni permesse e dati sintetici / One flow, up to five pages, allowed actions and synthetic data.
- [ ] Browser/versione e dispositivo reale o viewport registrati / Actual browser/version and real device or viewport recorded.
- [ ] Stato iniziale, prerequisiti e versione del sito registrati / Initial state, prerequisites and site version recorded.
- [ ] Percorso principale e almeno un errore significativo verificati / Main path and at least one meaningful error condition checked.
- [ ] Desktop e viewport mobile concordati verificati / Agreed desktop and mobile viewport checked.
- [ ] Tastiera, focus ed errori di input osservati / Keyboard, focus and input errors observed.
- [ ] Per ogni rilievo: passi, atteso, osservato, evidenza esistente / Each finding has steps, expected/observed behavior and actual evidence.
- [ ] Priorità spiegate, nessuna perdita economica inventata / Priorities explained, no invented revenue impact.
- [ ] Dati sensibili oscurati e consegna privata / Sensitive data redacted and evidence delivered privately.
- [ ] Report include limiti e parti non verificate anche con zero bug / Report includes limitations and untested scope even with zero findings.
- [ ] Accettazione, ricontrollo e chiusura accessi concordati / Acceptance, bounded recheck and access closure agreed.
